# PocketHUD — Карманный ушной суфлёр для Android

Автономное Android-приложение для мгновенного синхронного перевода итальянской речи в фоновом режиме с выключенным экраном.

- **Сквозная задержка:** ~350 мс (двунаправленный потоковый WebSocket `v1beta.GenerativeService.BidiGenerateContent`).
- **Фоновый режим:** Android Foreground Service с типом `microphone` и `PARTIAL_WAKE_LOCK` (телефон в кармане, экран погашен).
- **Звуковой пайплайн:** неблокирующая потокобезопасная очередь `LinkedBlockingQueue` (16 кГц PCM захват микрофона $\rightarrow$ 24 кГц PCM воспроизведение в наушники с поддержкой instant barge-in).
- **Сборка в облаке:** GitHub Actions компилирует чистый Debug APK за 90 секунд без необходимости ставить Android Studio или тяжелые SDK.

## Быстрый старт (1 клик)

### 1. Получение бесплатного API ключа Gemini
1. Перейди на [Google AI Studio: Get API Key](https://aistudio.google.com/apikey).
2. Нажми **"Create API key"** (выбери любой проект или создай новый).
3. Скопируй ключ (вида `AIzaSy...`).

---

### 2. Сборка APK через GitHub (автоматически)

Просто запусти готовый скрипт:
- **Дважды кликни по файлу** `setup_and_push.bat` (или запусти `.\setup_and_push.ps1` в PowerShell).

Скрипт сам:
1. Зафиксирует все файлы в ветку `main`.
2. Предложит открыть [github.com/new](https://github.com/new) для создания пустого репозитория `pocket-hud`.
3. Привяжет remote и отправит код (`git push -u origin main`).
4. Автоматически запустит сборку в GitHub Actions и откроет страницу статуса.

#### Ручной способ (если предпочитаешь консоль):
```bash
git remote add origin https://github.com/<твой-логин>/pocket-hud.git
git push -u origin main
```

---

### 3. Скачивание и установка на смартфон

1. Через ~1.5–2 минуты после пуша зайди в свой репозиторий на GitHub во вкладку **Releases** (или **Actions** $\rightarrow$ последний запуск $\rightarrow$ секция **Artifacts**).
2. Скачай файл `app-debug.apk` на смартфон.
3. Открой файл и разреши установку (при необходимости включи "Установка из неизвестных источников" для браузера/проводника).
4. Запусти **PocketHUD**, вставь свой API Key и нажми **"ЗАПУСТИТЬ В ФОНЕ"**.
5. Разреши доступ к микрофону и уведомлениям.
6. *(Рекомендуется для Xiaomi/Samsung)*: В свойствах приложения (О приложении $\rightarrow$ Батарея/Питание) выбери **"Без ограничений"** (Unrestricted), чтобы система не усыпляла микрофон при длительной блокировке экрана.
7. Выключи экран кнопкой питания, положи смартфон в карман и надень наушники — суфлёр активен!

## Запасной вариант: Instant Web HUD (без APK)

В папке `docs/index.html` находится полнофункциональная браузерная версия HUD:
1. В репозитории GitHub перейди в **Settings** $\rightarrow$ **Pages**.
2. В секции **Build and deployment** выбери **Source: Deploy from a branch**, ветка **main**, папка **/docs**, нажми **Save**.
3. Через 30 секунд открой полученный HTTPS-адрес (`https://<твой-логин>.github.io/pocket-hud/`) в браузере смартфона.
4. Введи API Key и нажми **СТАРТ**.
