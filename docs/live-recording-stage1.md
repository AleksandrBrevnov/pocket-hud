# Этап 1: Gemini Live и запись из общего PCM

Авторизация: пользователь разрешил изменения PocketHUD и сборку тестового APK; текущая задача — первый этап согласованного плана. Конспект из аудио не входит в этот релиз.

- R1. Единственный AudioRecord; архив получает PCM16 mono 16 kHz до программного усиления. Нет параллельного MediaRecorder.
- R2. Отдельная ограниченная очередь записи, WAV-фрагменты по 10 минут. Переподключения WebSocket не перезапускают архив. Переполнение/ошибка диска явно помечают незавершённую запись.
- R3. После остановки запись доступна из приложения для прослушивания/экспорта. Незавершённые файлы не выдаются за полные.
- R4. Готовность отправки привязана к поколению и экземпляру сокета. Старый setupComplete/onClosed не меняет новое соединение. Повторный выбор уже выбранного движка/микрофона ничего не перезапускает.
- R5. Переход на каскад завершает Live-файл; запись каскада не обещается. Старые файлы не удаляются, имена уникальны.
- R6. Официальная Gradle-сборка, JVM-тесты реальной логики очереди/WAV и gate, проверка AXML versionCode/versionName и подписи v2/v3.

Порядок: контрактные тесты → Red в CI → реализация → Green → независимый аудит → официальный APK → бинарная инспекция. На телефоне отдельно проверить звук, выключенный экран, отключение сети, повторный выбор режима и сохранённую длительность. Нет подключённого телефона: эти пункты остаются непроверенными.

Объём PCM: около 1.92 MB/мин, 115.2 MB/час. Смена движка создаёт отдельный интервал записи. На этом этапе не сохраняются интервалы каскада; интерфейс должен говорить об этом явно.
