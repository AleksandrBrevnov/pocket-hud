# Проверка Soundcore Work D3200 на Motorola Edge 50 Pro

PocketHUD **1.0.59-d3200**, прошивка диктофона **03.56**.

1. Останови фирменное приложение soundcore, если оно держит BLE. Включи Bluetooth. Оставь диктофон в режиме ожидания, выбери в PocketHUD **Soundcore Work**, затем запусти суфлёр.
2. Дождись сообщения **«Начни запись кнопкой D3200»**. Нажми кнопку записи на диктофоне в течение 90 секунд, пока суфлёр подключён. Если запись уже шла и появилось сообщение, что её ID недоступен, закончи её кнопкой и начни новую.
3. Произнеси короткую фразу по-итальянски. Проверь русский перевод. Останови суфлёр, проверь, что запись на диктофоне продолжается, затем останови её кнопкой D3200.
4. Оставь выбранным **Soundcore Work** и нажми **«ЛОГ»**. В журнале будут событие о начале записи 1A/06, запрос живого аудио 1A/07 и счётчики Opus, PCM и отправки в Gemini, если соответствующие этапы пройдены.
