# Проверка Soundcore Work на Motorola Edge 50 Pro

Сборка подготовлена для Android 16 и Soundcore Work D3200 8 GB с firmware 03.56. Начни с проверки на уже установленной прошивке. Протокол сверялся по [tacshi/Soundcore](https://github.com/tacshi/Soundcore/blob/main/PROTOCOL.md) и [OpenBean](https://github.com/imraywang/openbean/blob/master/docs/PROTOCOL.md). Физическая проверка на 03.56 ещё впереди.

## Подключение

1. В системных настройках открой приложение soundcore и нажми «Остановить принудительно», чтобы оно освободило BLE-соединение. Включи Bluetooth. Подключи наушники как медиавыход, если хочешь проверить звук перевода.
2. Установи PocketHUD, открой приложение, выбери **📡 Soundcore Work** и предоставь доступ к ближайшим устройствам и микрофону. Движок должен переключиться на **Gemini Live**. Каскадный режим должен стать недоступен.
3. Убедись, что диктофон свободен. Запусти суфлёр. Проверь последовательность **GATT → MTU → ECDH → запись PocketHUD → realtime с file ID → Opus → PCM**. Названия этапов видны в статусе и в Logcat.
4. Произнеси короткую фразу по-итальянски рядом с D3200. Проверь, что в PocketHUD появился русский перевод, а звук слышен через наушники. После остановки суфлёра проверь, что D3200 завершил запись. В Logcat ожидается подтверждение остановки.

## Запись, начатая на самом диктофоне

1. Запусти запись кнопкой D3200. Запусти суфлёр с источником **Soundcore Work**.
2. Проверь статус «Запись уже идёт». Если прошивка отклонит новый формат списка, PocketHUD запросит старый формат.
3. Останови суфлёр и проверь на диктофоне, что запись продолжается. Заверши её кнопкой D3200 после проверки.

## Диагностика 03.56

Сохрани журнал по одному тегу с подключённой отладкой по USB:

```text
adb logcat -d -v time -s PocketHUD-D3200:I
```

Для подтверждения нужны строки с версией, принятым realtime-заголовком, счётчиками Opus/PCM и результатом двух проверок остановки. Если появился статус «Устройство отказало в realtime BLE-запросе», сохрани журнал и закончи тест на этой прошивке. Если после потери связи диктофон показывает продолжающуюся запись, проверь её состояние на самом D3200.

К дистанциям 2, 3, 5 и 7 м переходи после подтверждения PCM и перевода.
